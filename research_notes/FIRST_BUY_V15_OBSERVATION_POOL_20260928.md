# 第一买点 V15：3+ 连板观察池 → Day1 → Day2 决策（2026-09-28）

## 核心思路

每天收盘后，只要主板个股仍处于 3 连板及以上，就进入实时观察池。

之后：
- 继续涨停：继续留在观察池，不产生买点；
- 第一次不再涨停：这一天定义为 Day1（第一次断板 / 第一次分歧事件）；
- 下一交易日定义为 Day2；
- Day2 根据竞价/开盘和盘中确认决定是否买入；
- 不允许 Day3 继续沿用同一个旧事件。

这使样本生成从“先认定龙头，再等首阴”升级为“所有当时真实可观察的 3+ 连板先进入候选生命周期”。

## 为什么这样扩容

以前主要从 4+ 连板和核心龙头出发，候选样本天然过少。
但市场每周持续产生 3板、4板、5板及更高连板票。

V15 将“观察资格”和“买入资格”彻底拆开：
- 观察资格尽可能宽：3+ 连板；
- 买入资格仍严格：由 Day1 质量 + Day2 行为 + 历史 walk-forward 模型决定。

因此扩大的首先是训练样本，不是无条件交易次数。

## V15 Day1 样本定义

必须满足：
1. 前一交易日连续涨停高度 prior_streak >= 3；
2. 当前交易日不再涨停；
3. 是该连板序列后的第一次断板；
4. 有下一交易日数据；
5. Day2 gap 在主板可解释涨跌停范围内。

3板与4+不等价。
模型显式加入：
- prior_streak
- is_three_board
- is_four_plus
- market_height_prev
- height_gap
- height_ratio

让历史数据学习“3板什么情况下值得买，什么情况下只是普通跟风”。

## 观察池记录

V15 额外保存 observation_pool.csv：
- 每天所有仍在涨停的 3+ 连板票；
- 当日连板高度；
- 当日市场最高板；
- 与市场最高板的差距；
- 月份、周次；
- 成交额和收盘价。

这样未来实盘可以在票断板之前就知道它已经处于观察名单，而不是事后回溯。

## 五档候选池

V15 同时比较：
- mid
- wide
- ultra
- max
- all3plus

其中 all3plus 不设成交额、振幅、量能、题材地位硬门槛，只要求 3+ 首次断板语义成立。

它只是最高召回训练池，不代表全部买入。

## Day2 买入决策

继续使用两阶段方式：
- 高评分：Day2 open 可直接执行；
- 中评分：先观察前30个完整分钟；
- 满足确认后最早第31分钟 open 执行；
- 极端低开不能开盘直接买。

模型输入同时包含：
- 连板高度/市场相对高度；
- 近5/10/20日涨幅；
- 历史涨停密度；
- Day1涨跌幅、实体、振幅；
- Day1爆量程度；
- Day1收盘/VWAP与收盘位置；
- 是否触及涨停；
- Day2 gap；
- 前30分钟修复、VWAP、区间位置、量能等。

## 主要验收指标

V15 不以“样本越多越好”单独验收，而要求：

1. Day1 样本数量按月/周显著高于 V14；
2. walk-forward 实际交易数量增加；
3. 单独统计 3板来源交易的胜率、均值、最差交易；
4. 单独统计 4+ 来源交易；
5. BALANCED / ACTIVE 的总平均收益保持为正；
6. 多月伪样本外至少一半验证月份非负；
7. 不能靠某一个极端大赢家掩盖大量亏损；
8. 若 3板整体质量明显差，则不是删掉全部3板，而是继续学习其有效子类型；
9. 不允许按具体股票代码、月份做特判。

## 目标

最终目标不是让所有 3+ 连板都交易，而是：

3+ 连板全部进入观察池
→ 产生大量真实 Day1 样本
→ 学习哪些结构 Day2 值得参与
→ 在不明显牺牲胜率与单笔期望的前提下，大幅提高可交易数量。

范围始终只是一买，不包含 R50、二买、生命周期、二次断板。
