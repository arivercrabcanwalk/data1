# 第一买点 V16：30日观察生命周期 + 二连板再武装

## 状态机
1. 新的 >=3 连板序列出现，进入 PRIMARY_ARMED。
2. 第一次非涨停日成为 Day1。
3. Day2 进行买入/PASS 决策，同时开启 30 个自然日观察窗口。
4. 30日内若重新达到至少 2 连板，进入 RECYCLE_ARMED。
5. 下一次断板成为新的 recycled Day1，再次在下一交易日做 Day2 决策。
6. recycled Day1 再开启新的 30 日窗口，可继续产生后续代次。
7. 若 30 日内没有达到新的 2 连板，则旧生命周期过期；未来新的 >=3 连板可开启新生命周期。

## 研究约束
- 生命周期样本生成与模型买/PASS独立，避免阈值变化改变历史样本成员。
- 初始周期要求 >=3 连板；30日内二波只要求 >=2 连板。
- 2连板必须在原30日窗口内形成；一旦已在窗口内再武装，允许等待其之后第一次断板，即使断板日期略超过原窗口。
- 每个新 Day1 都重新开启30日观察窗口。
- Day2 仍是唯一决策日，不沿用旧 Day1 到 Day3。
- 30分钟确认后最早第31分钟 open 成交。

## 核心审计
结果必须同时报告：
- primary / recycle Day1 数量；
- 30日 re-arm 成功率；
- recycle 占新增样本比例；
- 总交易数 / 胜率 / 平均收益 / 中位数 / 最差单笔；
- primary vs recycle 交易表现；
- 2板再起 / 3板 / 4+ 来源表现；
- generation 0/1/2/... 的表现；
- 多月 walk-forward 稳定性。

胜率定义：已执行交易中 ret > 0 的比例。
成功率同时提供两个口径：
1. 交易成功率 = 正收益交易 / 已执行交易；
2. 观察再武装成功率 = 完整30日窗口内重新形成 >=2 连板的生命周期 / 完整30日窗口。
