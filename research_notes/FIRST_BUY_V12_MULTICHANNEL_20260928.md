# 第一买点 V12 多通道升级（2026-09-28）

研究边界：只研究一次买点 / 第一天爆量分歧 / 真实首阴 -> 下一交易日入场。禁止混入 R50、生命周期、二次买点、再次断板/再次回封。

工程边界：本轮研究、审计、代码、回测与结果保存全部通过 GitHub / GitHub Actions 完成，不依赖 Remote Desktop Commander。

统计边界：以下历史收益来自已经看过的历史样本或由这些样本启发的规则研究，不属于真正样本外验证，不能把历史全胜当作未来胜率。

## 1. V11 的结构性漏票
1. D+1 高开超过旧 +8% 上限：高争民爆、神奇制药。
2. 超高板被一刀切排除：爱丽家居。
3. 极端低开开盘机械否决：哈药股份。
4. 6–7 板绝对高度有时足以自证核心：博云新材。
5. 缓存 lu 字段存在错误，必须按昨收与涨停价重新计算。

## 2. 暴力扩容被否定
GitHub Actions 用 2026-03 至 2026-08 全市场分钟数据重建日线、涨停与连板高度，得到 87 个“prior_streak>=4 的首次断板”基础事件。

简单用“接近市场最高板 + 放宽量能 + 多种 gap”扩容得到：
- 29 笔；
- H3 胜率 55.17%；
- H3 均值约 +2.93%；
- H3 最差约 -16.87%。

结论：V12 不替换 V10/V11 主干，只为经过反例检验的特殊结构增加独立入口。

## 3. 主干继续冻结
- V10/V11 的绝对核心、题材强度、家族排名、跟随活跃度等主干规则继续保留。
- core_age <= 8，超过必须重新完整认证。
- 修复缺失分钟数据后按原 VWAP 结构判定。
- 保留 4–5 板首断、6–7 板真实首阴重锚。
- 不使用 D+2 延续旧观察日。
- 不允许二次断板混入第一买点。
- 不整体下调 follower、family_rank、ret20、amount 等核心硬门槛。

## 4. 数据语义修复
V12 不再信任存量 lu 字段，而是用前收盘、适用涨停比例和分币四舍五入后的涨停价重新得到 lu_calc，并基于 lu_calc 重建连续涨停高度。停牌本身不把连板序列错误打断。

爱丽家居：07-27~07-31 为 5~9 板，08-06 收盘 24.79 等于涨停价 24.79，应为第 10 板；08-07 才是真正首次断板。旧缓存把 08-06 标成非涨停会直接漏掉该一买。

## 5. 通道 A：HIGH_GAP_HEIGHT_5PLUS
条件：
- prior_streak >= 5；
- 前一日高度距市场最高板 <= 1；
- 首次断板；
- event_ret >= 0；
- close/VWAP >= 0.98；
- close_loc >= 0.35；
- 仅本通道允许软爆量：vol_prev>=1.35，或 vol_median10>=2 且 vol_prev>=0.70，或 amount>=10亿且 range>=8% 且 vol_prev>=0.65；
- D+1 gap [8%,10.2%]；
- D+1 必须可成交，排除真正一字涨停。

历史 Mar-Aug 当前只选出高争民爆 08-05 -> 08-06：H3约+21.92%，H5约+25.27%。

## 6. 通道 B：HIGH_GAP_THEME_4
条件：
- prior_streak == 4；
- 首次断板；
- 观察日前一日已是题材 leader 或题材 rank1；
- 观察日盘中触及过涨停价；
- 严格爆量；
- event_ret >= 0；
- close/VWAP >= 0.98；
- D+1 gap [8%,10.2%]；
- 排除一字不可成交。

神奇制药 08-19 -> 08-20 符合；以 8.56 为模型入场，至 08-24 收盘 9.90，H3约+15.65%。

中化国际 06-15 虽 D+1 高开约+9.22%，但首断日没有触及涨停，题材排名也不够强，H3约-1.89%，因此被排除。

## 7. 通道 C：SUPER_HIGH_ABSORPTION
禁止“8+ 一律做”。8+ 宽口径样本当前为 2，一正一负。

候选条件：
- prior_streak >= 8；
- 高度距市场最高板 <= 1；
- 软爆量；
- event_ret >= -2%；
- close_loc >= 0.80；
- close/VWAP >= 1.02；
- D+1 gap [-3%,8%]。

爱丽家居 08-07 -> 08-10：H3约+15.70%，H5约+10.30%。

当前可比样本极少，因此本通道暂为 experimental / 半仓级，等待未见样本验证。

## 8. 通道 D：PANIC_REPAIR_5PLUS
条件：
- prior_streak >= 5；
- 高度距市场最高板 <= 1；
- 首次断板；
- 软爆量；
- event_ret >= +3%；
- close_loc >= 0.60；
- close/VWAP >= 0.98；
- D+1 gap [-10.2%,-4%]；
- 绝不在开盘直接买；
- D+1 前60分钟必须重新收复观察日收盘价，第一次分钟收盘重新站上时才允许入场。

哈药股份：07-17 五板后首断 +7.89%，07-20 约-9.94%开，09:53 收复观察日收盘价 5.33；模型 H3约+12.20%。

ret floor 2/3/4% 与 reclaim 30/60/90m 邻域测试当前都只选到哈药，但样本仍为1，暂为 experimental / 半仓级。

## 9. 通道 E：TRUE_RED_6_7_HEIGHT_OVERRIDE
条件：
- prior_streak 6–7；
- 高度距市场最高板 <= 1；
- 首次断板；
- 严格爆量；
- event_ret 在 [-8%,0)；
- close/VWAP >= 0.95；
- D+1 gap [0%,8%]。

当前 Mar-Aug 全市场只选到博云新材 04-21 -> 04-22，H3约+16.75%，H5约+18.22%。同类低开样本存在明显亏损，因此本通道不扩到 D+1 低开；样本为1，暂为 experimental / 半仓级。

## 10. 宝鼎：只做合格 probe 的加仓，不生成新候选
generic reclaim 再次被否定：
- 30m reclaim：4笔，H3胜率25%，均值约-1.74%，最差约-13.42%；
- 60m reclaim：5笔，H3胜率40%，均值约-1.10%，最差约-13.42%；
- 90m 与60m接近。

因此宝鼎必须先通过 V11 的核心、新鲜度和首断条件。D+1 小低开仍先保持 probe；只有前60分钟重新收复观察日收盘价，才允许从 probe 加仓。

宝鼎 05-14 约10:02收复，模型确认价约34.83；H3约+1.46%，H5约+7.38%。

## 11. 第一买点语义清洗
最终观察事件在重算后的序列中必须直接来自 prior_streak>=4 的首次断板。1板、2板后的再次断板、老龙头第二波、R50、生命周期均不得进入本项目。

当前桥数据对风范股份相关日期显示 prior_streak 只有1；在没有证明它对应另一条合法首断事件前，V12 不把它计入清洗后的第一买点总数。

## 12. 反例审计
继续复核全市场新增样本后发现：
- 德龙汇能：ret20约2.2%、followers2，不是绝对核心；
- 宝鼎08-11：rank13、ret20为负，不是新的第一核心；
- 香江控股：题材历史字段缺失，证据不足；
- 江钨装备：rank1但followers2，样本不足；
- 长裕集团：followers2；
- 大胜达：rank5；
- 汉森制药：H3约-10.66%；
- 旭光电子：H3约-1.82%；
- 水发燃气：leader/rank1仍有H3约-11.10%；
- 美诺华：leader/rank1、followers18仍有H3约-2.20%。

结论：板数、题材第一、followers多、leader=true 的任何单因子都不够，V10/V11 的多层核心 + 事件 + D+1 结构必须保留。
