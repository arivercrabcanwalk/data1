# 方法论证据边界：退学炒股 / 92科比

本文件只用于定义研究框架，不把网络二手整理包装为本人原话，也不把任何历史收益叙事作为策略有效性的证明。

## 92科比

### 证据较强：直播录音/公开视频留档
- 小宇宙《04.短线核心-情绪周期｜92科比直播录音》：https://www.xiaoyuzhoufm.com/episode/65485eb4c248305a89fed144
  - 公开录音整理明确描述四阶段：主升、高位震荡、主跌、低位试错。
  - 其中强调主跌阶段降低仓位/尽量空仓，低位试错阶段要重新积极试错。
  - 用途：定义周期状态机和仓位/模式切换语义。

### 证据中等：官方号/二手整理
- 淘股吧官方号转载《92科比：龙头-补涨-切换-空仓》：https://www.sohu.com/a/459763424_120100059
  - 提出“龙头、补涨、切换、空仓”的概括；同时区分补涨更偏旧周期仍有赚钱效应时的延续，切换更偏旧周期已经出现明显亏钱效应后的新方向试错。
  - 这是整理者的结构化总结，不能标注为92科比逐字原话。
- 东方财富二手整理《情绪周期的进化理解—92科比》：https://caifuhao.eastmoney.com/news/20241001183044852192320
  - 对低位震荡、主升、高位震荡、主跌及题材预判、分歧介入等作二次整理。
  - 仅作交叉验证。

### 落地约束
- P1 龙头主升：只做已被前一晚确认为主线核心、且盘中重新获得板块跟随的候选。
- P4 补涨：旧主线仍保持正赚钱效应、龙头已经打开空间，低位同共性形成梯队。
- P5 切换：旧高位已形成明确负反馈，新共性必须形成独立梯队。
- P6 冰点试错：低位试错不是重仓抄底；只允许预先定义的小风险预算。
- 主跌/退潮：默认降低总风险；不是为了“每天都有交易”强行找机会。

## 退学炒股

### 证据中等：历史文章整理/转载
- 《退学炒股 - 我和小明》转载整理：https://www.waihuibang.com/fxschool/fxstory/158450.html
  - 可见的核心行为原则包括：没有自己的标的不乱买；收盘后复盘做好计划；不因踏空而随意交易；强调不断学习。
- 《我和小明》完整跟帖整理：https://www.qingzhouquanzi.com/449.html
  - 整理了关于连续成功导致过度自信、连续失败导致回撤，以及选择高成功率场景等反思内容。
- 百度文库转载：https://wenku.baidu.com/view/39fabbd06b1aff00bed5b9f3f90f76c661374ca2.html
  - 可用于交叉验证“复盘做好计划、没有标的不乱买”等文本，但仍然属于转载，不是原站原帖证据。

### 落地约束
- 交易前必须有计划和可验证预期；盘中临时起意要单独标记。
- “踏空焦虑、亏损后急于回本、连续盈利后过度自信”不作为玄学心理描述，而进入错误标签和行为统计。
- 单笔亏损不自动触发规则修改；必须区分正常模式亏损和认知/计划/执行错误。
- 每日复盘输出必须包含“明日允许做什么、禁止做什么、什么条件下计划失效”。

## 两套方法的共同可量化部分

1. 市场并非每天都有同样的交易赔率，仓位和模式要随周期变化。
2. 题材和核心地位先于单纯K线形态；强势股不自动等于核心股。
3. 计划必须在交易前形成，盘后复盘用于纠错和积累样本，而不是事后重新解释。
4. 亏钱效应本身是重要信号：它决定应该继续做旧主线、做补涨、寻找切换，还是降低风险。
5. 模式进化采用 `Observation -> Hypothesis -> Sample -> Rule Change`，禁止 `Loss -> 调参直到历史亏损消失`。

## 真实性与幸存者偏差

网络交易人物的历史收益、交割单、语录和转载存在真实性、选择性传播、幸存者偏差和市场制度变化问题。本项目只把可交叉验证的方法论当作研究假设，再由严格点时数据与前向回测检验；任何人物叙事都不能替代统计验证，也不构成收益承诺或投资建议。
