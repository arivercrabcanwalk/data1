# 短线复盘系统规范 v1（知识层冻结稿）

> 本规范先于正式 7 月回测冻结。目的：减少“看到结果再解释”的自由度。

## 1. 证据层级

### E0：GitHub 原始行情事实
`2026-07/**/minute1.parquet` + `daily_stock_status.parquet`。用于价格、成交、涨跌幅、触板/封板代理、带动性、MFE/MAE、真实成交约束。

### E1：当日/历史收盘归档事实
收盘后涨停、跌停、炸板、连板梯队、题材归属、当日催化。只允许 T+1 生效。

### E2：直播/原始内容留档
用于定义龙头、补涨、切换、空仓、周期、计划、纠错等概念，不用于选择历史个股。

### E3：官方号/社区二手整理
只能做交叉验证和术语解释，不得伪装成本人原话。

## 2. 每日复盘流水线

收盘后严格执行：

1. **市场层**：广度、成交、涨停/跌停、炸板、连板高度、昨日强势股溢价。
2. **周期层**：冰点 -> 修复 -> 升温 -> 高潮 -> 降温/分歧 -> 退潮。
3. **题材层**：逐题材统计广度、持续性、梯队、容量、催化、赚钱/亏钱效应。
4. **地位层**：总龙、主线龙、容量核心、弹性核心、补涨、切换先锋、跟风候选。
5. **交易层**：每个模式只允许在其周期前置条件满足时进入观察池。
6. **个人复盘层**：交易逻辑、预期、触发、执行、退出、错误标签、MFE/MAE、R倍数。
7. **次日预期层**：写出超预期/符合预期/低于预期/切换四种情景和失效条件。
8. **更新层**：当天结论最早下一交易日生效。

## 3. 市场周期判定

不依赖指数单点，而使用：

- 全市场红盘比例/中位收益
- 涨停与跌停数量（保留不同源口径）
- 炸板率/封板率
- 连板数量和最高板
- 昨日涨停次日表现
- 高位核心负反馈
- 题材集中度

### 冰点
广度极差、跌停/大面扩散、昨日强势股显著负反馈中的至少两类同时出现。策略目标不是抄底，而是寻找“最先修复且能带动板块”的新核心证据。

### 修复
冰点/退潮后，广度改善，跌停明显减少，核心股率先修复，至少一个题材形成可识别梯队。

### 升温
赚钱效应扩散，主线梯队完整，核心和容量中军共振，但尚未出现极端一致。

### 高潮
广度/涨停/主线扩散明显偏高，后排大量补涨、预期高度一致。此阶段风险不是“市场差”，而是次日分歧的赔率下降。

### 分歧/降温
核心仍可能强，但后排淘汰、炸板增加、晋级率下降。只研究核心分歧，不做无地位跟风。

### 退潮
高位亏钱效应扩散、昨日强势股负反馈、多个老题材同步走弱。默认降低频率和总风险。

## 4. 题材强度 ThemeScore

不以网站的“主线”标签直接作为答案。来源标签只是一个证据通道。

每个题材 T 日生成以下原始特征：

- `theme_limitup_count_source_votes`：多来源涨停归属数量/投票
- `theme_member_adv_ratio`：题材成员红盘比例（GitHub）
- `theme_member_median_ret`
- `theme_turnover_share`：题材成交额/全市场成交额
- `theme_early_strength`：10:00 前强势成员比例
- `theme_board_height`：该题材最高连板
- `theme_ladder_depth`：首板/2板/3板+梯队完整性
- `theme_persistence_3d`：近3日持续存在天数
- `theme_persistence_5d`
- `theme_followthrough`：昨日核心/涨停成员今天的收益与晋级表现
- `theme_broken_board_rate`
- `theme_big_loss_rate`
- `catalyst_confidence`：催化来源等级与来源数量
- `source_vote_count`

最终评分采用**横截面排名**而非针对7月调绝对阈值：

`ThemeScore = 0.20*广度 + 0.15*梯队 + 0.15*持续性 + 0.15*容量 + 0.15*核心强度 + 0.10*次日/当日跟随质量 + 0.10*催化可信度 - 风险惩罚`

权重在正式回测前冻结；不允许为了消除某笔7月亏损单独改权重。

## 5. 题材生命周期

对每个题材维护状态机，而不是月底回看后一次性标记：

`未激活 -> 启动 -> 确认 -> 发酵 -> 高潮 -> 分歧 -> 回流/二波 -> 退潮 -> 休眠`

状态更新只依赖截至 T 收盘的数据。若老题材退潮后新题材首次形成独立高强度，则标记“切换候选”，而不是自动判定新主线。

## 6. 个股地位 Leadership

### 总龙
全市场辨识度/高度/带动性综合最强的候选。必须有市场级证据，不能只因连板最高而自动当总龙。

### 主线龙
主线内部在高度、主动性、板块带动中占优。

### 容量核心
题材中成交容量大、对指数/板块资金有承载作用，通常不是纯连板高度定义。

### 弹性核心
20cm/高弹性方向中最具辨识度和带动性的候选。

### 补涨
旧主线仍有赚钱效应时，低位出现与主线相同或可解释共性的扩散票。

### 切换先锋
旧周期已经明显产生亏钱效应后，新共性率先聚焦。必须与旧亏钱共性有显著差异。

### 跟风
自身上涨主要发生在题材已经启动以后，且其异动不能显著提升板块后续5/10/20分钟表现。

## 7. 带动性 Lead-Lag

对候选核心在其关键异动分钟 `t0` 计算：

- 同题材成员 `t0+5m`、`t0+10m`、`t0+20m` 平均超额收益
- 同题材红盘成员增量
- 新触及涨停/新高成员增量
- 核心先动还是板块先动

`Leader` 必须更多表现为“它动以后别人跟”，而不是“大家涨完它才跟”。

## 8. 预期系统

每个交易日晚必须冻结四种场景：

1. **超预期**：核心、容量、梯队和广度同时优于前一晚预案。
2. **符合预期**：主线正常分化，核心承接正常。
3. **低于预期**：核心低于关键预期且题材跟随恶化。
4. **切换**：老主线低于预期，同时新题材出现独立聚焦。

盘中不能用“最终收盘结果”重写早盘预期。

## 9. 六个研究 Playbook

### P1 龙头主升
前置：修复/升温，主线排名前列，核心身份已在前一晚确立。
触发：当日核心表现不低于预期且出现板块跟随。
禁止：高潮末端后排一致、无板块跟随、临时把强势股晋升为龙头。

### P2 核心弱转强
前置：T-1 已是核心。
触发：竞价/开盘弱于基准预期，随后主动收复并伴随同题材改善。
禁止：普通强股V形反抽、退潮后无题材支持的单股拉升。

### P3 核心分歧转一致
前置：核心发生正常分歧而非逻辑破坏。
触发：抛压消化 + 重新获得跟随。
禁止：只因为价格翻红就定义“修复”。

### P4 补涨
前置：原主线仍有正赚钱效应、龙头打开空间。
触发：低位同共性股票形成新梯队且不是单点脉冲。
禁止：老周期已经主跌还把低位票叫补涨。

### P5 切换
前置：旧高位出现明确负反馈。
触发：新共性连续获得资金聚焦并形成独立梯队。
禁止：旧主线只是日内小分歧时频繁换题材。

### P6 冰点试错
前置：冰点/退潮。
触发：新核心候选率先逆势并具有带动性。
风险：仅小仓/低频；失败后不报复性继续试错。

## 10. 高潮与退潮规则

- 高潮不是无条件空仓，而是**禁止后排一致追高**，只保留核心超预期/首次有效分歧研究。
- 退潮不是机械永久0仓，而是降低总风险；若出现明确冰点修复/切换证据，允许预先定义的小仓试错。
- 回撤保护必须有“恢复条件”，禁止出现账户跌破某线后整月永久停止学习的死锁。

## 11. 个人复盘字段

每笔交易至少记录：

`market_stage, theme, theme_rank, lifecycle, role, playbook, pretrade_expectation, trigger, invalidation, entry_time, entry_price, size, exit_time, exit_price, MFE, MAE, R, pnl, execution_deviation, error_tags, screenshot_ref, next_action`

## 12. 规则更新协议

规则只能在达到事先门槛时调整：

- 单笔失败：记录，不改规则。
- 同一错误标签在同一模式出现 2 次：进入观察。
- 3 次：下一交易日开始模式降权/暂停，等待新样本。
- 模式样本达到最低统计量后，才允许判断胜率/赔率/期望值。
- 所有变更写入 `rule_change_log.csv`：`decision_date`, `effective_date`, `evidence_before_change`, `old_rule`, `new_rule`, `reason`。

任何改动都不能回溯影响已发生交易。

## 13. 正式回测准入门槛

以下全部通过才准进入收益回测：

- 23日 GitHub 市场事实完整
- 每日至少一个语义历史源，绝大多数交易日至少两个事实源
- 题材/成员/梯队可以关联到股票代码或有明确未匹配审计
- 20项知识层输出具备
- T+1 有效时间测试通过
- 禁止未来字段测试通过
- 来源冲突未被静默覆盖
- 规则规范已经冻结并有版本号

未通过时只修数据/实现问题，不做收益优化。
