# 7月复盘驱动短线系统：回测前硬性规范

## 0. 原则

本目录是后续7月回测的唯一方法论入口。旧 `backtest/` 目录、旧策略信号、旧回测结果不得被导入。

行情执行层只允许读取 `2026-07/**/minute1.parquet` 与同日 `daily_stock_status.parquet`。题材/新闻/核心地位层允许使用公开互联网资料，但必须记录发布时间，并按点时可得性控制：收盘后资料最早只能用于下一交易日；盘中资料只能在其发布时间之后使用；禁止用月末总结反推月初决策。

## 1. 交易决策的六层结构

### L1 市场/情绪层

每天收盘固定计算：全市场上涨/下跌家数、涨跌幅中位数、成交额、涨停数、跌停数、炸板数、封板率、连板高度、昨日涨停/连板次日表现、高位股大面数量、20cm/10cm赚钱效应。

输出 `market_phase`：`试错/修复/主升/高潮/分歧/退潮/冰点`。市场状态只决定“是否允许出手”和总风险预算，不直接产生个股买点。

### L2 题材层

每个活跃题材建立点时记录：
- `theme_name`
- `catalyst`：政策、产业、事件、业绩、涨价、产品、海外映射等
- `first_seen_at`
- `evidence_source`
- `stage`：`new_trial / confirm / accelerate / divergence / repair / retreat / dead`
- `breadth_evidence`：涨停/大涨代表数量、是否有板块联动
- `continuity_days`
- `leader_integrity`：核心是否仍强、是否补跌/天地板
- `persistence_score`

题材不能只因“一天涨幅第一”就定义为主线。主线至少需要：持续性、梯队、核心、容量/辨识度、赚钱效应中的多数条件成立。

### L3 核心地位层

“核心”是相对关系，不是单一技术评分。每个题材按角色记录：
- `market_high`: 市场高度/情绪锚
- `theme_leader`: 题材最高辨识度/最强带动者
- `capacity_core`: 大成交额、能承载大资金并代表板块强弱
- `trend_core`: 非纯连板但趋势持续、反复承接资金
- `elastic_core`: 20cm/高弹性核心
- `supplement`: 补涨
- `follower`: 跟风
- `negative_anchor`: 跌停/大面/天地板等负反馈锚

核心确认至少考虑：题材内相对强度、连续性、成交额/容量、领涨时点、板块跟随数、分歧抗跌、回封/修复能力、次日溢价。禁止用“过去几日涨得多”替代核心地位。

### L4 预期差层

每天收盘必须冻结次日预期，不允许盘后改写：
- 题材预期：加强/延续/分歧/退潮/修复
- 核心预期：高开强更强、弱转强、正常分歧、低于预期
- 验证窗口：竞价、09:45、10:00、10:30、14:30

只有实际表现相对“昨晚已写下的预期”出现可定义的超预期或符合模式条件时，才进入交易触发层。

### L5 模式库层

围绕复盘体系只允许以下抽象模式，先不引入其他技术体系：
1. `leader_divergence_to_consensus`：主线核心第一次有效分歧后重新转强。
2. `leader_weak_to_strong`：核心在预期偏弱/正常分歧情况下开盘后出现超预期承接并重新取得题材主导。
3. `low_level_switch`：旧主线退潮，新的低位题材经板块联动+核心带动确认后的切换。
4. `supplement_after_leader_confirmed`：龙头明确后，补涨梯队在明确时点出现；必须先有龙头确认，禁止无锚补涨。
5. `ice_point_repair`：市场冰点后，率先形成群体赚钱效应的题材核心修复。
6. `cash`：没有符合条件的题材/核心/预期时空仓本身就是模式。

每个模式必须包含：前置市场状态、题材阶段、核心角色、触发条件、禁止条件、入场后失效条件、T+1限制下的退出方案、最大仓位、样本统计。

### L6 执行/风控层

- 信号在某分钟结束后确认，最早下一分钟 `open` 成交。
- 严格执行A股T+1，买入当日不得卖出。
- 处理涨跌停、停牌/ST/新股状态、100股整数手。
- 计入手续费、印花税、双边滑点。
- 同一题材/同一逻辑的多只股票按“相关仓位”计，不允许伪分散。
- 错误交易快速退出；真正走成核心右尾不使用机械小止盈截断。

## 2. 每日复盘的固定产物

每个交易日必须生成一条不可回写的 `daily_review`：
1. 市场状态及证据
2. 主线/支线/退潮题材
3. 题材阶段变化
4. 核心梯队与负反馈锚
5. 当日赚钱/亏钱效应
6. 自己每笔交易：买入前预期、实际触发、执行、MFE/MAE、结果
7. 错误分类：认知/题材/地位/预期/择时/执行/仓位/纪律/FOMO/模式外
8. 未参与但应记录的机会
9. 次日预期和if-then计划
10. 规则是否允许更新

## 3. “不断进化”的因果约束

进化路径固定为：`Observation -> Hypothesis -> Sample -> Rule`。

禁止：一笔亏损后直接调阈值；看到后半月赢家后回头修改月初规则；用月末统计决定月中仓位。

允许：
- 新样本只更新到当日收盘后的模式统计。
- 连续同类错误触发临时降频/降仓/暂停观察。
- 模式规则升级需要达到预先设定的最小样本量，并保存旧规则版本与生效日。
- 市场环境变化可以改变“允许哪些模式”，但判定必须来自当时可见数据。

## 4. 题材信息防未来函数规则

1. `source_publish_at <= decision_at` 才可直接使用。
2. 17:00以后发布的收盘复盘最早 `next_trading_day` 生效。
3. 月度回顾只用于研究审计，绝对不进入7月交易信号。
4. 当天新爆发题材若没有当时可用的盘中公开来源，则当天只记录、不追溯性交易；次日才纳入计划。
5. 股票所属题材若仅由后来的概念标签确认，不得倒灌；优先使用当日新闻/复盘明确点名的代表股。

## 5. 回测启动硬门槛

以下全部为 PASS 才允许启动回测：
- [ ] 23个交易日全部有点时复盘记录
- [ ] 每日资料有发布时间和原始URL
- [ ] 每日主线/支线/退潮题材可解释
- [ ] 每个可交易题材至少有核心角色或明确标记“无可交易核心”
- [ ] 每日次日预期已冻结
- [ ] 所有模式前置/触发/失效/退出/仓位规则固定
- [ ] T+1、涨跌停、费用、滑点、停牌/新股约束固定
- [ ] 日内新题材无历史来源时不允许事后追溯交易
- [ ] 回测代码禁止读取旧 `backtest/` 和8月数据
- [ ] 输出必须包含逐笔交易、逐日复盘、规则版本变化与失败样本

回测结果不设收益率目标作为调参目标。收益只是验证结果；若失败，首先判断是题材识别、核心地位、预期差、执行还是风险预算的问题。
