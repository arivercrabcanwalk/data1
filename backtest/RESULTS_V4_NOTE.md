## 0. 结论先行

V4 成功把新笔记里的“先识别交易模式，再决定买卖/仓位”的思想转成了严格因果的程序，但**本次 2026-03 至 2026-08 历史回放没有超过 V3**。

因此：

- `main` 上的 V3 冻结生产基线继续保留；
- V4 保持研究覆盖层，不以本次历史收益替换 V3；
- 不根据本次结果继续调 `technical_core_proxy`、调整天数、市场模式阈值等参数；
- 新笔记里依赖产业/订单/基本面的部分，必须等点时数据后再做真正量化。

这次“没有突破”本身是有效研究结论，不能为了追求更高回测收益而隐藏。

## 4. 新笔记中被历史消融支持的两条规则

### 4.1 高位 + 高波动时缩小风险，同时允许更低的第二根大阳线支撑

V4 fixed：+5.16%，最大回撤 -6.00%。

关闭该规则：

- 收益：**-2.40%**
- 最大回撤：**-12.07%**
- PF：0.841

说明“位置高、筹码不稳时不能因为止损更宽就维持原仓位”是有价值的风险思想。V4 的实现是：只有存在第二个真实大阳线支撑时才允许把技术止损下移，同时把风险预算和单票名义仓位乘数都减半。

注意：这是 human-seen 历史消融证据，不能因为这组结果就把它宣称为已完成样本外验证。

### 4.2 震荡模式大涨后不贪，最早下一交易日兑现

V4 fixed：+5.16%。

关闭 `range_big_rise_next_open`：

- 收益降至 **+2.93%**
- 最大回撤扩大至 **-7.47%**
- PF 降至 1.185

正式执行保持严格因果：只有完整日 K 已经收完后才知道“当天大涨”，因此程序最早下一交易日开盘卖，不会看完当天涨幅后又按当天高价成交。

## 5. 故地重游：经过模式过滤后有所改善，但仍不能升级

V4 把故地重游限制在 `range/mixed`，并增加调整/技术核心代理后：

- 7 笔已平仓
- 累计 P&L：约 **+12,033**
- 胜率：42.86%
- 平均百分比收益仍约 **-1.32%**

去掉故地重游后，V4 收益从 +5.16% 降到 +4.33%，说明它在本次组合资金权重下略有正贡献。

但样本只有 7 笔，而且平均交易收益仍为负，不能据此推翻 V3 对故地重游的淘汰结论。它继续作为研究模块，不晋升。

## 6. 真正暴露的核心问题：价格技术代理不能替代“产业核心”

V4 为了在缺少产业/基本面数据时近似“核心标的”，预注册了 `technical_core_proxy`：相对强弱 + 流动性 + 近期标志性大阳线参与度。

历史回放证明这种替代不可靠。

V3 的 40 笔平步青云交易按 V4 note gate 回看：

- 被 V4 gate 保留：17 笔，累计约 **+25,585**；
- 被 V4 gate 过滤：23 笔，累计约 **+138,999**。

其中一些 V3 大赢家只是因为“距离 20 日高点不足 3 天”或 `technical_core_proxy` 未达到人为工程阈值而被过滤。

所以本轮最重要的认知不是“把 0.62 改成 0.58”，而是：

> **笔记中的‘通信核心 / 液冷核心 / 订单率先兑现 / 基本面技术共振’不是纯价格横截面分数能够忠实替代的。**

继续在同一 3-8 月上调这个阈值，只会把研究变成过拟合。

## 8. 冰轮式三浪左侧：修复独立风险子账户后的研究结果

最初实现发现一个结构冲突：普通 V3 风险引擎在弱市可能把总仓位降到 0%，这会使“下跌周期里的左侧三浪急跌试仓”永远无法成交。

这是实现冲突，不是参数优化。因此修复为独立左侧研究子账户：

- 单笔风险预算为常规模块的 0.5 倍；
- 左侧子账户总敞口最多 50%；
- 必须先出现日线 raw wave-3 divergence；
- 下一交易日真实出现约 2.5% 以上急跌；
- 低点稳定至少 8 根一分钟 K；
- 从低点反弹至少约 0.8%；
- 确认分钟结束后只能按下一分钟 open 成交。

本次数据：

- raw wave3 候选：7,504
- 技术门槛通过：30
- 次日分钟确认：13
- 半仓独立研究账户最终完成闭合：6 笔
- 收益：**+0.40%**
- 最大回撤：**-1.89%**
- PF：**1.151**
- 胜率：33.33%
- 3 笔快速 support break 全亏，合计约 -22,006
- 3 笔持有至 time stop，合计约 +26,050

该样本太少，且依赖少数赢家，不能晋升。

更重要的是，新笔记明确把这种左侧交易成立的原因之一放在“真实收入 / 已接订单 / 基本面优势”上。当前仓库没有点时历史订单/基本面，因此：

- `raw_wave3_production_gate_count = 0`
- 正式生产左侧模块保持关闭
- 技术版只保留研究输出

## 9. 纯游资农业/食品潜伏：为什么没有强行塞进程序

新笔记本身把这类模式描述成：低市值、缺乏业绩支撑、涨停前难有征兆、依赖游资合力和资金博弈，并要求三五天没预期就退出，不能把超短做成长线。

当前数据没有：

- 点时历史总市值；
- 点时业绩/订单；
- 题材归属；
- 游资/龙虎榜身份和资金协同行为。

因此 `speculative_ambush_enabled = false`。不能用 K 线假装已经识别出“50 亿以下、无业绩、游资合力”。

## 12. 下一阶段需要的数据，而不是更多参数

要真正消化这篇笔记并进一步突破，优先补的数据是：

1. `sector_map_history.csv`：历史逐日板块/产业链归属；
2. `fundamental_history.csv`：点时订单、收入兑现、产业核心评分、当时总市值；
3. 历史题材/涨停原因/龙虎榜或资金参与数据，用于研究纯游资模式；
4. 1-2 月行情用于 March wave warm-up；
5. 公司行为/复权点时数据。

在这些缺口补齐之前，继续只用 3-8 月价格数据调“核心分数”“调整天数”“震荡阈值”，会提高回测自由度，却降低可信度。

## 13. 冻结研究纪律

- 不因 V4 +5.16% 低于 V3 就在同一数据上重新搜索参数；
- 不因某个消融版本历史更好就自动晋升；
- V3 production 不被 V4 research 覆盖；
- V4 研究代码和失败结论保留在 PR #4；
- 真正的晋升证据必须来自新增的点时信息和/或之后未参与设计的新时间样本。
